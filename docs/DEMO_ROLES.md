# Demo role guide
Use the **Demo role** switcher in the top bar (no password — *not authentication*). Each role gets its own landing page, navigation and permitted actions. Permissions are editable in **Administration → Roles & permissions** (System Administrator).

| Role | Lands on | Can do (highlights) |
|---|---|---|
| System Administrator | Executive dashboard | Everything incl. role permissions, settings, audit |
| Club Owner / Board | Executive dashboard | View all, approve memberships, refunds, **write-offs**, closures |
| General Manager | Executive dashboard | All operations, approvals, write-offs, closures, settings (not role editing) |
| Golf Operations Manager | Golf Operations | Tee sheet, check-in, starter, caddie override/settle, carts, closures, events |
| Membership Officer | Membership | Applications, plans, dues billing, renewals (cannot approve/suspend) |
| Reservations Officer | Reservations | Bookings, waitlist, check-in, no-show |
| Caddie Master | Caddie Management | Attendance, rotation, overrides (with reason), replacement, settlements |
| Starter / Marshal | Check-In & Starter | Ready, release, delay, checkpoints, incidents, complete round |
| Golf Cart Supervisor | Carts | Assign/dispatch/return, inspection, report defects, return to service |
| Course Superintendent | Maintenance | Work orders, inspection/completion, **course restrictions** |
| Maintenance Staff | Maintenance | Update work orders, labor, materials (cannot inspect/complete) |
| Cashier / Finance Officer | Finance | Payments, shifts, refunds (no write-off), POS/range |
| Café Manager / POS Staff | POS | POS, discounts above staff limit, voids/refunds, stock |
| Tournament Coordinator | Events | Events, registrations, flights, scoring, tee blocks |
| Member / Golfer | Portal | Mobile portal: book, cancel, privileges, account, events, feedback |

Try a permission check: as *Cashier* open a charge → **Write off** is disabled; switch to *General Manager* and it works (audited).
